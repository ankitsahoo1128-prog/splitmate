🚀 **Introducing Splitmate – Smart Expense Sharing Web Application!**

Excited to share my project **Splitmate**, a smart expense-sharing web application designed to make managing shared expenses easier and more convenient.

💡 **What is Splitmate?**

Splitmate helps users manage shared expenses, split bills among friends, and keep track of who owes whom. It aims to make group expense management simple, transparent, and hassle-free.

🎯 **Key Features:**
- Easy expense management.
- Simplified bill splitting.
- Track shared expenses among friends.
- User-friendly interface.

🛠️ **Technologies Used:**
- Frontend: Web Development
- Backend: Backend Development
- Database: MongoDB
