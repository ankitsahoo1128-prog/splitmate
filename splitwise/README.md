# splitwise 
Description:   A simple expense‑sharing web application inspired by Splitwise. This project helps groups of friends, roommates, or colleagues track shared expenses and settle balances easily. The goal is to provide a beginner‑friendly yet functional tool for learning full‑stack development concepts.  Features:  Add and manage expenses with descriptions and amounts  Automatic balance calculation for each member  Clean and responsive user interface  Option to view history of transactions  Lightweight backend for storing and retrieving data  Tech Stack:  Frontend: HTML, CSS, JavaScript  Backend: Node.js / Express (or your chosen stack)  Database: SQLite / MongoDB (depending on setup)  Usage:  Clone the repository.  Install dependencies with npm install.  Run the server using npm start.  Open the app in your browser and start adding expenses.  Future Improvements:  User authentication and login system  Group creation and management  Export balances to PDF/Excel
